The set called \emph{pair} holds the CEPII and history features of Table~\ref{tab:features}, the other forecast sets add lyrics, running order, Trends or Trends and running order.

Ridge regression picks its penalty from 13 values between 0.001 and 1000 by leave-one-out cross-validation on the training rows. Gradient boosting is the histogram version with depth 4, a learning rate of 0.06 and 300 iterations, in the split with a minimum leaf size of 200. The random forest has 200 trees with a minimum leaf size of 20 and looks at half of the features at each split. The chance baseline uses the seed 20260501 and the models use 0.
